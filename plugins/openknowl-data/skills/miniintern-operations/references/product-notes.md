# 제품 동작 및 주의사항

이 파일은 운영팀 답변에 필요한 제품 동작과 관리자 화면 관련 주의사항을 담는다.

## 사용 원칙

- 제품 동작은 현재 운영 기준으로 정리된 내용만 답한다.
- PRD나 회의록의 아이디어는 현재 반영 여부가 확인되지 않으면 답변하지 않는다.
- 화면 위치, 버튼명, 상태값은 정제된 기준에 있는 경우에만 말한다.

## 데이터성 질문 주의

관리자에서 보이는 수치, 신청자 목록, 수료자 목록, 기업별 현황은 실제 데이터 조회 영역이다. 이런 질문은 `openknowl-data:search-data`로 처리해야 한다.

## 확정된 제품 동작

배포 완료된 릴리즈 노트 기준. 괄호는 배포 시점.

### 상품·참여

- **파트너형 미니인턴** (2025-02): 기업이 프로젝트를 등록하면 프로젝트 단위로 지원자를 모집한다. 기업은 1~3명 선발, 이력서·포트폴리오 기반 1차 선발, 최종 작업물 검토 후 상금 지급. 채용 연계 가능. 상세페이지에 [전형 과정] 이미지 제공 (2025-03).
  - 프로세스: 기업 신청 → 과제·상금 협의 → 빅브라더 개최 → 모집·홍보 → 참여자 신청(기업이 지정한 서류 제출) → 기업 1차 선발(적합자 없으면 개최 취소 가능) → 계약 → 프로젝트 수행(재택/출근 등 기업 협의 방식) → 기업 결과물 검토·상금 대상자 선발 → 운영진 상금 지급.
  - **참여자는 신청 단계에서 본인인증 필수** (상금 지급 계좌 확인 목적).
  - **1차 선발·결제 후에는 상금 대상자가 없어도 결제 금액이 환불되지 않는다** — 기업 안내 시 필수 고지.
  - 상금은 수수료 공제 후 참여자에게 지급된다 (수수료율은 담당자 확인).
  - **서류 취급 차이 주의**: 파트너형은 기업이 직접 선발하므로 과제수행계획 등 지원 서류가 기업에 전달된다. 교육형/채용형의 과제수행계획은 운영진 선발용으로 기업에 전달하지 않는다.
  - 빅브라더 파트너형 운영 단계: 전체 / 지원 / 1차 선발 / 종료 / 질문. 1차 선발 후 이전 단계로 되돌리기 가능.
- **역량 리포트 유료 상품** (2026-02): 미니인턴 참여자의 평가 결과·결과물을 AI로 분석해 역량 성장 추이를 보여주는 유료 상품. **미니인턴 신청 시부터 종료 후까지 언제든 구매 가능.** 출시와 함께 이용약관·개인정보처리방침·환불처리규정이 개정됨. 구매 내역·환불 처리는 빅브라더 결제 관리 페이지에서 진행.
- **AI 역량 평가** (2026-03): 개최 시 운영자가 선택한 경우에 한해 결과물 평가 기준에 AI 역량 5가지가 추가된다. 해당 미니인턴은 목록에 [AI 역량 포함] 태그가 노출되고, 평가 결과가 역량 리포트에도 반영된다.
- **미니인턴 신청 내역 화면** (2026-02): 참여자는 마이커리어 > 미니인턴 신청 내역에서 진행상태별 구분, 해야 할 행동·일정, 제출 파일·평가 결과·피드백을 확인할 수 있다. 채용형은 이력서 업로드와 연결 공고 지원 현황도 여기서 처리한다.

### 참여자 화면·계정

- **조회수 집계** (2025-04): 미니인턴 리스트 조회수는 카드 클릭과 링크 접근을 모두 집계하며, 이미 종료된 프로젝트는 집계하지 않는다.
- **소셜로그인·통합계정** (2024-08): 카카오 가입 지원, 카카오 가입 시 미니인턴 카카오채널 자동 친구추가. 이메일/전화번호가 같으면 카카오·네이버 계정이 통합계정으로 합쳐진다. 계정 관련 문의 시 이 동작을 염두에 둘 것.
- **동의 항목** (2025-05): 광고성 마케팅 수신 동의와 채용 제안(구 헤드헌팅) 동의가 분리돼 있다. '헤드헌팅' 워딩은 구직자 화면에서 '맞춤형 채용 제안 받기'로 변경됨 (2025-04).
- **참가이력 상태 체계**: 참가이력은 신청중/선발/수료/우수수료, 합불 상태는 합격/불합격/불참으로 관리된다 (2025-03 기준. 당시 두 체계의 워딩 불일치와 미수료·미제출 구분 부재가 리뉴얼 안건이었음 — 현재 화면 기준은 확인 필요).
- **탈퇴 회원 처리** (2024-06 결정): 탈퇴한 회원의 이메일은 변형 표기(탈퇴 마킹)로 저장되고, 재가입 시 기존 계정과 별개로 취급된다. 탈퇴 이력 관련 계정 문의 시 참고.
- **취업성과금**: 수료 후 채용관 지원과 연계된 취업성과금 제도가 있다. 금액·지급 기준은 화면 문구와 담당자 기준으로 확인할 것 (이 레퍼런스에서 단정하지 않는다).

### 운영자(빅브라더)·기업 화면

- **챗봇 문의 채널** (2026-04~05): 구직자·기업 대상 1:1 챗봇이 전체 페이지 우측 하단에 상시 노출된다. 키워드 자동응답 + AI 생성 답변으로 1차 응대하고, 자동 응대가 어려우면 대화 내역이 운영팀에 인계된다. 자세한 처리 흐름은 `customer-support.md` 참조.
- **알림톡 발송** (2025-08): 미니인턴 주요 프로세스별 안내 알림톡을 빅브라더에서 발송할 수 있다 (자동화는 미완).
- **선발 탭 정보** (2025-05): 교육형/채용형 선발 탭과 파트너형 1차 선발 탭에서 구직자의 최근 접속시간과 선택 분야를 볼 수 있다.
- **지원자 정보 노출 제한**: 채용절차법 준수를 위한 기업회원의 지원자 정보 접근 차단 정책이 적용돼 있다 (2024-11). 기업은 최종 결과물이 제출되고 최종 선발된 구직자만 검토할 수 있다 (2025-02).
- **지원서류 파기 정책**: 채용절차법에 따라 지원서류는 채용 확정일로부터 180일 후 파기된다. 최종합격 후 입사자는 보관, 입사 포기자와 불합격자는 확정일로부터 180일 후 파기되며 이후 기업이 상세 페이지에 접근하면 파기 안내가 표시된다.
- **미니인턴 → 채용공고 전환**: 교육형/채용형 미니인턴은 종료 후 채용공고로 전환되는 구조가 있다. 전환·마감 세부 조건은 내부 기준을 확인할 것.
- **기업·관리자 정보 직접 수정** (2025-06): 운영팀이 빅브라더에서 기업 정보와 기업관리자 정보를 개발팀 없이 직접 조회·수정할 수 있고, 수정 내용은 기업관리자페이지에 즉시 반영된다. **주의: 관리자 정보를 '퇴사'로 변경하면 다른 값으로 되돌릴 수 없다.**
- **기업별 관리 페이지** (2025-12): 운영자가 기업별 미니인턴 개최 현황과 채용관 공고 현황을 한 화면에서 볼 수 있다.
- **기업 CRM 메일 수신자**: 공고 등록 완료·지원자 발생 등의 알림 CRM 메일은 마스터·인사담당자 권한 보유자에게 고정 발송된다. 공고별 담당자 지정 발송은 지원되지 않는다 (2025-12 기준).
- **기업관리자페이지**: 기업정보(기본/상세/이미지 3단계) 관리, 미니인턴 개최 신청, 최종결과물 검토, 기업 가이드 페이지를 제공한다. 기업정보 등록·수정은 마스터 권한 전용.
- **개최 신청 잠금**: 과제 신청완료 이후에는 기업이 작성 내용을 수정하거나 다시 확인할 수 없다.

## 알려진 주의사항

- 채용관 공고의 채용 상태가 합격/불합격으로 바뀌어도 지원자에게 알림톡이 자동 발송되지 않는다 (2025년 12월 기준, 개선 검토 중). 지원자는 플랫폼에 접속해야 결과를 알 수 있어 관련 문의가 잦다 — 결과 확인 위치를 안내한다.

- 참여자 화면에서 '미제출로 인한 미수료'와 '평가 결과 미수료'가 명확히 구분되지 않는다 (2026년 1월 기준, 개선 논의 중). 미수료 문의를 받으면 어느 쪽인지 내부에서 확인하고 답한다.
- 참여자용 FAQ 페이지(`miniintern.com/helpcenter/qna`)와 기업 가이드 페이지는 업데이트 주기가 일정하지 않다는 내부 지적이 있었다. 페이지 내용과 현재 운영 기준이 다르면 운영 기준을 우선하고 페이지 수정을 요청한다.

## 알려진 공백

- 관리자 화면별 상세 매뉴얼(빅브라더 화면 단위 조작법)은 아직 포함하지 않는다. 운영팀 검토를 거쳐 확정된 화면 기준만 이후 버전에 추가한다.
- 교육형/채용형 유형의 공식 정의 문구가 정리돼 있지 않다.
- 릴리즈 노트는 2026년 6월 배포분까지 미니인턴 운영 관련 항목만 반영했다. 채용관·M클래스·해피폴리오 전용 변경과 그 이후 배포는 내부 Release Note 원본을 확인한다.
