# 미니인턴 서비스 지식

이 파일은 운영팀이 미니인턴을 설명할 때 쓰는 확정 지식만 담는다.

## 미니인턴 설명 원칙

- 미니인턴은 기업 과제 또는 프로그램을 통해 참여자가 실무 경험을 쌓고, 기업은 참여자 역량을 확인할 수 있도록 운영되는 서비스다.
- 운영 설명에서는 "참여자", "기업", "과제", "모집", "선발", "수료" 같은 도메인 용어를 사용한다.
- 내부 DB 컬럼명, 관리자 개발 용어, 임시 프로젝트명은 고객 응대에 사용하지 않는다.

## 운영팀 답변 기준

- 서비스 소개가 필요하면 한 문단으로 간단히 설명한다.
- 기업 고객에게는 모집 목적, 참여자 경험, 운영 일정, 결과 확인 방식 중심으로 설명한다.
- 참여자에게는 신청, 선발, 과제 수행, 결과 확인, 수료 기준 중심으로 설명한다.
- 확정되지 않은 상품 구성이나 가격은 단정하지 않는다.

## 신규 운영자용 짧은 설명

미니인턴은 기업 또는 기관의 실무형 과제를 기반으로 참여자를 모집하고, 참여자가 과제를 수행한 뒤 결과와 수료 여부를 관리하는 운영 서비스다. 운영팀은 모집 정보 확인, 신청/선발 상태 관리, 과제와 일정 안내, 결과 및 수료 관련 문의 대응을 담당한다.

## 개최 유형

- 기업이 개최 신청 시 선택하는 유형은 **교육형**과 **채용형**이다.
- 교육형/채용형의 상세 정의 문구는 아직 정리된 기준이 없다. 유형별 차이를 단정하지 말고, 설명이 필요하면 담당자 확인을 안내한다.
- **파트너형 미니인턴** (2025년 2월 출시):
  - 기업이 해결하고 싶은 문제를 프로젝트로 등록하면, 적합한 지원자를 프로젝트 단위로 모집하는 형태.
  - 기업은 프로젝트별로 지원자를 1~3명 선발할 수 있고, 이력서·포트폴리오 검토로 1차 선발을 진행할 수 있다.
  - 최종 작업물 제출 후 기업이 검토하고 '상금' 형태로 보상을 지급하며, 우수 지원자는 협의를 통해 채용 연계 가능성이 있다.

## 참여자 여정 (확정 흐름)

1. 모집 페이지에서 신청
2. OT 종료 후 합불(선발) 처리
3. OT — 운영: 과제·일정 안내 / 기업: 기업·과제 소개, 질의응답
4. 과제 수행 — 기획안 작성법 온라인 강의(최종기획안 제출일까지 수강 가능), 도움자료 제공
5. 중간기획안 제출 → 현직자 멘토의 1:1 서면 중간피드백
6. 최종기획안 + 이력서 제출
7. 수료평가 (제출 확인 후 최종기획안 평가)
8. 최종결과 발표 — 수료자에게 수료증 발급

## 수료 / 미수료 구분

- 미수료는 두 가지로 나뉜다: **최종기획안 미제출**로 인한 미수료, **제출했으나 평가 결과** 미수료.
- 미수료자에게는 현재 별도 확인서가 발급되지 않는다 (2026년 1월 기준. 참여확인증 발급은 개선 아이디어 단계로, 확정되면 갱신할 것).
