# 미니인턴 운영 지식 인덱스

질문을 먼저 분류한 뒤 필요한 파일만 읽는다.

| 질문 유형 | 읽을 파일 |
|---|---|
| 서비스 정의, 상품 유형, 용어 | `service.md` |
| 모집, 선발, 과제, 수료, 결과 안내 등 운영 절차 | `operation-playbook.md` |
| 기업 고객/참가자 응대, 답변 초안 | `customer-support.md` |
| 운영팀 내부 업무 흐름, 관리자 화면 기준 | `admin-workflows.md` |
| 제품 동작, 관리자 화면 제약, 알려진 주의사항 | `product-notes.md` |
| 데이터 조회 스킬로 넘길지 판단 | `routing.md` |
| 제외하거나 보류한 원본 자료 기준 | `excluded-sources.md` |

## 판단 순서

1. 숫자, 통계, 기간별 추이, 순위가 필요한지 확인한다.
2. 실제 DB 조회가 필요하면 `routing.md`를 읽고 `openknowl-data:search-data` 사용을 안내한다.
3. 절차, 정책, 응대, 예외 처리 질문이면 해당 운영 레퍼런스를 읽는다.
4. 레퍼런스에 없는 내용은 추측하지 않는다.
