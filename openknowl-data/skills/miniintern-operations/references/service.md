# 미니인턴 서비스 지식

이 파일은 운영팀이 미니인턴을 설명할 때 쓰는 확정 지식만 담는다.

## 미니인턴 설명 원칙

- 미니인턴은 기업 과제 또는 프로그램을 통해 참여자가 실무 경험을 쌓고, 기업은 참여자 역량을 확인할 수 있도록 운영되는 서비스다.
- 운영 설명에서는 "참여자", "기업", "과제", "모집", "선발", "수료" 같은 도메인 용어를 사용한다.
- 내부 DB 컬럼명, 관리자 개발 용어, 임시 프로젝트명은 고객 응대에 사용하지 않는다.

## 운영팀 답변 기준

- 서비스 소개가 필요하면 한 문단으로 간단히 설명한다.
- 기업 고객에게는 모집 목적, 참여자 경험, 운영 일정, 결과 확인 방식 중심으로 설명한다.
- 참여자에게는 신청, 선발, 과제 수행, 결과 확인, 수료 기준 중심으로 설명한다.
- 확정되지 않은 상품 구성이나 가격은 단정하지 않는다.

## 신규 운영자용 짧은 설명

미니인턴은 기업 또는 기관의 실무형 과제를 기반으로 참여자를 모집하고, 참여자가 과제를 수행한 뒤 결과와 수료 여부를 관리하는 운영 서비스다. 운영팀은 모집 정보 확인, 신청/선발 상태 관리, 과제와 일정 안내, 결과 및 수료 관련 문의 대응을 담당한다.
