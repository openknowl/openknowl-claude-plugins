# 제품 동작 및 주의사항

이 파일은 운영팀 답변에 필요한 제품 동작과 관리자 화면 관련 주의사항을 담는다.

## 사용 원칙

- 제품 동작은 현재 운영 기준으로 정리된 내용만 답한다.
- PRD나 회의록의 아이디어는 현재 반영 여부가 확인되지 않으면 답변하지 않는다.
- 화면 위치, 버튼명, 상태값은 정제된 기준에 있는 경우에만 말한다.

## 데이터성 질문 주의

관리자에서 보이는 수치, 신청자 목록, 수료자 목록, 기업별 현황은 실제 데이터 조회 영역이다. 이런 질문은 `openknowl-data:search-data`로 처리해야 한다.

## 확정된 제품 동작

- **파트너형 미니인턴** (2025년 2월 배포): 기업이 프로젝트를 등록하면 프로젝트 단위로 지원자를 모집한다. 기업은 1~3명 선발, 이력서·포트폴리오 기반 1차 선발, 최종 작업물 검토 후 상금 지급. 채용 연계 가능.
- **기업관리자페이지**: 기업정보(기본/상세/이미지 3단계) 관리, 미니인턴 개최 신청, 최종결과물 검토, 기업 가이드 페이지를 제공한다. 기업정보 등록·수정은 마스터 권한 전용.
- **개최 신청 잠금**: 과제 신청완료 이후에는 기업이 작성 내용을 수정하거나 다시 확인할 수 없다.

## 알려진 주의사항

- 참여자 화면에서 '미제출로 인한 미수료'와 '평가 결과 미수료'가 명확히 구분되지 않는다 (2026년 1월 기준, 개선 논의 중). 미수료 문의를 받으면 어느 쪽인지 내부에서 확인하고 답한다.
- 참여자용 FAQ 페이지(`miniintern.com/helpcenter/qna`)와 기업 가이드 페이지는 업데이트 주기가 일정하지 않다는 내부 지적이 있었다. 페이지 내용과 현재 운영 기준이 다르면 운영 기준을 우선하고 페이지 수정을 요청한다.

## 알려진 공백

- 관리자 화면별 상세 매뉴얼(빅브라더 화면 단위 조작법)은 아직 포함하지 않는다. 운영팀 검토를 거쳐 확정된 화면 기준만 이후 버전에 추가한다.
- 교육형/채용형 유형의 공식 정의 문구가 정리돼 있지 않다.
- 주 단위 배포 릴리즈 노트는 아직 정제하지 않았다. 최신 제품 변경사항은 내부 Release Note 원본을 확인한다.
