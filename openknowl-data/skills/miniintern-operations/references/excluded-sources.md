# 제외 및 보류한 원본 자료 기준

Notion export 전체를 스킬에 넣지 않는다. 이 파일은 왜 제외했는지 설명하기 위한 내부 기준이다.

## 플러그인에 넣지 않는 파일 유형

- 이미지: `png`, `jpg`, `jpeg`, `webp`, `gif`
- 영상: `mov`, `mp4`
- 디자인 원본: `ai`, `eps`
- 압축 파일: `zip`
- 오피스/문서 원본: `pptx`, `pptm`, `pdf`, `hwp`, `docx`, `xlsx`, `xls`

## 답변 근거로 쓰지 않는 자료

- 중복 `_all.csv`
- 개인 업무기록
- 임시 메모
- 오래된 광고 소재
- 회계감사 로그
- 법인카드 관련 문서
- 계약서 또는 계약 협의 자료
- 개인정보가 포함될 수 있는 고객/참가자 원본 목록
- 현재 기준인지 확인되지 않은 회의 중 아이디어

## 보류 자료

다음 자료는 운영팀 검토 후 확정 기준만 추출해서 별도 버전에 반영한다.

- 회의록
- PRD
- 스프린트 회고

릴리즈 노트는 2026년 6월 배포분까지 정제 완료 (미니인턴 운영 관련 항목만, `product-notes.md`에 반영).
운영 ↔ 프로덕트 협업 시트는 문의 스레드 2건 정제 완료 (아래 참조).

## 2차 정제(v1.0.17~)에서 반영·제외한 자료

반영:

- Release Note 26건 중 미니인턴 운영 관련 배포 항목 → `product-notes.md`, `customer-support.md`(챗봇 문의 처리 흐름), `admin-workflows.md`
- 운영 ↔ 프로덕트 문의 "미니인턴 진행 및 영업 관련 문의" (2025-09, 운영팀 답변): 인바운드 경로 분류, 개최 승인/거절 사유, VOC 패턴
- 운영 ↔ 프로덕트 문의 "맞춤형 채용 제안 받기 활용 상황 문의" (2025-09): 종료 후 취업지원서비스 연계 프로세스

의도적으로 제외:

- 후기 SNACK 업로드 인터뷰 12건 — 참가자 실명·인터뷰 원문 포함 (개인정보)
- 기업고객 관리시트 운용 절차 — 원문에서 취소선 처리돼 현행 여부 불명 + 내부 구글 시트 URL
- 개최비·채용수수료 안내 금액 — 변동 가능, 계약 인접
- 주요 진행 일정 폴더의 스프린트 일정·킥오프 스텁 — 임시 진행 기록
- 채용관·M클래스·해피폴리오 전용 릴리즈 항목 — 스킬 경계 밖
- 만족도조사 원본 xlsx — 바이너리 + 기업 식별 정보

## 5차 정제(유저 인사이트 + 회의록 + 마케팅&교육운영)에서 반영·제외한 자료

유저 인사이트 42건 전수 제목 검토, 미니인턴 운영 관련 9건 열람. 회의록 최상위 ~190건 전수 제목 검토, 운영 결정 후보 10건 열람. 반영:

- 팔로업 중단 기준, 개최 리드타임, 표준 일정 개요, 만족도조사 운영 구조 (유저 인사이트)
- 중간피드백(서면/온라인 1:1)·최종피드백 현행 프로세스, "미수료 불만은 설명 부족에서 기인" 경험칙 (최종피드백 상품화 회의의 '진행 현황' 부분)
- 파트너형 전체 프로세스·본인인증 필수·상금 환불 불가·서류 취급 차이 (파트너형 운영방안 회의)
- 참가이력 상태 체계, 탈퇴 회원 이메일 처리, 메일 발송 프로세스(help 계정, 대량 발송 사전 공유)

의도적으로 제외:

- 유저 인사이트의 Next Step 제안 전부 — 미확정
- 최종피드백 '상품화' 기획 부분 — 논의 중 단계 (현행 아님)
- 회의록 내 멘토·참여자 실명, 기관·대학·기업명, 내부 메일함/드라이브/독스 링크
- 피드백 멘토 비용, 파트너형 수수료율 — 금액 정책
- 미니인턴 운영 방향 1·2 — 조직 방향 논의로 미확정
- 개발팀 채용형 과제 선정 — 개별 과제 원문
- 마케팅&교육운영 협업 시트 — 2021~2023 광고 자료 아카이브와 개별 마케팅 요청 건 (오래된 광고 소재, D등급 확정)
- 스프린트/데일리스크럼/회고/OKR/디자인·개발 기술 회의록 — 제외 클래스

## 4차 정제(전 폴더 재스캔)에서 반영·제외한 자료

macOS 파일명이 NFD 유니코드라 초기 한글 파일명 필터가 무효였음을 발견, NFC 정규화 후 전 폴더 재스캔. 반영:

- 협업 요청 보드 '미니인턴 개최/운영 요청' 템플릿 항목
- 미니인턴 인스타그램·SNACK 가이드: 홍보 협업 접수 절차·규격
- 알림톡 구체화 검토 회의록 2건: 알림톡 시나리오 계열, 일정 변경 실무 관행 (수동 발송 결정)
- 유저 인사이트 '채용 결과 알림톡 자동 발송': 채용 결과 알림 미발송 주의사항
- 이력서 첨삭 요청 가이드 (2023-10): 첨삭 서비스 운영 방식 개요만 — 최신 여부 확인 필요 표기

의도적으로 제외:

- 이력서 첨삭 가이드 내 지원자·멘토·직원 실명, 메일 원문, 단축 링크, 멘토비 단가 — 개인정보·금액
- 미니인턴 이력서 작성 가이드(자소서 작성 팁) — 참여자 대상 콘텐츠라 운영 기준 아님, 필요 시 원본 배포
- 업무 링크(휴가·복지비·회의실), 주요 일정 작업 트래커 — 총무·일정 기록
- 최상위 미니인턴 폴더 — 연기된 스프린트 회의의 PRD 아이디어 조각뿐 (미확정)
- 데이터 요청 보드 '메일 리스트 기준 요청' 다수 — 데이터 추출 요청 (search-data 영역)
- 알림톡 검토 회의록의 트리거 설계안 세부 — 구현 여부 미확정 부분
- 기술혁신사업부 도서관 — 개발 서적 목록 (무관)
- 마케팅&기획 협업 시트의 해피폴리오 콘텐츠 목록, 투자사업부 사업 제안서 — 스킬 경계 밖

## 3차 정제(유지보수 목록)에서 반영·제외한 자료

유지보수 작업 보드 328건 중 정책성 티켓 6건만 열람. 반영:

- 계정 승계 안내 기준, 마스터 퇴사 시 수동 승인 절차, ATS 지원서류 180일 파기 정책, 운영 취소 건 데이터 삭제 처리 방식, 반복 요청 유형 패턴(파일명 수준 집계)

의도적으로 제외:

- 개별 버그 티켓 원문 전체 — 일회성 수정 완료 건이라 운영 기준 아님
- 계정 문의 이슈처리 리스트 — 유저 실명 폴더 구조 (개인정보)
- 티켓 내 기업명·담당자 성명·이메일·재직증명서 첨부 — 개인정보/기업 식별 정보
- 2023년 개최 유형 수동 변경 우회 절차 — 이후 개최 신청 폼이 유형 선택을 지원해 현행 아님으로 판단
- M클래스 QA 폴더 — M클래스 영역 (스킬 경계 밖)
- 스킬업 약관·튜터 계약서·타서비스 약관 사본 — 계약/법무 인접

## 1차 정제(v1.0.16)에서 반영·제외한 자료

반영 — 확정 기준만 추출:

- 미니인턴 개최 및 운영 가이드 (사업부 간 협업 시트): 개최 절차, 필요물, 기업 신청 절차, 베이직/케어/파트너십/프로모션 운영 범위
- 사업부 협업 가이드 회의록: 단계별 운영 프로세스 표, 수료평가 기준, 사업부 간 R&R 케이스 (일반화하여 반영)
- 파트너형 미니인턴 릴리즈 노트: 배포된 제품 동작
- 유저 인사이트(미제출/중간피드백 구조 분석): 수료 구조·미수료 구분·현행 한계 등 현재 상태 서술만 반영

같은 문서에서 의도적으로 제외:

- 개최 수수료·상품별 단가·운영 비용 비율 전액 (회계·계약 인접, 변동 가능)
- 특정 기업명·사업명이 붙은 개별 개최 사례
- 참가자 수·수료율 등 통계 수치 (search-data 영역이며 시점 고정 위험)
- 개선 제안·아이디어 단계 항목 (참여확인증 발급, 알림톡 자동화 등 — 확정 시 반영)
- 내부 구글 시트/드라이브 URL (레퍼런스에는 존재만 언급)

전체 제외:

- 할리갈리(개인 월별 업무기록), 동료피드백, 주간/월간 보고
- 이용약관·환불·튜터 계약서 검토 자료 및 타서비스 약관 사본
- Idea Board 제안 문서, 데이터 요청 보드
- OKR 문서 (목표·수치 중심, 운영 기준 아님)
