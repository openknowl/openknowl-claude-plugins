# 미니인턴 운영 플레이북

이 파일은 확정된 운영 절차만 담는다. 세부 기준이 문서화되어 있지 않으면 단정하지 않는다.

## 기본 운영 흐름

1. 모집 정보 확인
2. 모집 페이지 또는 프로그램 정보 점검
3. 신청자 접수 상태 확인
4. 선발 또는 합격 상태 관리
5. 과제 및 일정 안내
6. 제출 또는 참여 상태 확인
7. 결과 및 수료 상태 안내
8. 후속 문의 대응

## 개최~수료 전체 프로세스 (운영 가이드 기준)

단계별 주체와 대략적 소요기간. 일정 협의 시 이 기준으로 역산한다.

| 단계 | 소요 | 비고 |
|---|---|---|
| 기업 섭외 | 2~3주 | |
| 과제 협의 | 3~5일 | 기업 소통 지연이 잦음 |
| (선택) 강연자 섭외 | 1주 | 기업·과제 확정 후 가능 |
| 미니인턴 개최 | 2일 | 커버이미지 제작, 랜딩 페이지 생성 |
| 홍보물 제작 | 2일 | 포스터, 인스타그램 게시물 |
| 참여자 모집·홍보 | 2주 | |
| 오리엔테이션(OT) | 1일 | 운영: 과제·일정 안내 / 기업: 소개·질의응답 |
| 기획안 작성법 강의 | - | 온라인, 최종기획안 제출일까지 수강 가능 |
| 도움자료 제공 1~3차 | 각 1일 | 3차는 최종 제출 전 체크리스트 |
| 중간피드백 | 1일 | 현직자 멘토 1:1 서면 피드백 |
| 수료평가 | 3~5일 | 최종기획안·이력서 제출 확인 → 최종기획안 평가 |
| 최종결과 발표 | 1일 | 수료증 발급 |

- 사업부 간 개최 요청은 **희망 OT 일자로부터 최소 8주 전**에 협업 요청 보드로 접수한다.

## 개최 요청 시 필요한 것 (기업/요청 부서에서 받아야 함)

- 미니인턴 커버이미지: **592 x 444px, 최대 30MB, JPG/PNG** (흰색 배경에 기업 로고 양식)
- 미니인턴 개최신청서 최종본 (과제 협의 완료 필수)
- 기업/과제 관련 이미지 5장 내외 (상세페이지 삽입용)
- 진행 일정: 모집마감일 / 선발일 / 중간제안서 제출일 / 최종제안서 제출일 / 결과 발표일 / OT일
- OT 장소 (오프라인 시 상세 주소)
- 운영팀 검토 후 개최까지 **1~2일** 소요

## 기업의 개최 신청 절차 (안내용 확정 절차)

1. 미니인턴 회원가입
2. 기업관리자 등록 — 최초로 기업을 등록한 계정은 담당자 내부 심사 후 **마스터 권한** 부여. 이후 가입하는 해당 기업 구성원은 마스터가 승인.
3. 기업정보 작성 — 기본 정보 → 상세 정보 → 이미지 정보 순. **기업정보 등록·수정은 마스터 권한자만 가능.**
4. 미니인턴 개최 신청 — 프로필 > '미니인턴 개최 신청' > 유형(교육형/채용형) 선택 > '추천 미니인턴 불러오기'로 과제 작성 > 신청완료.
5. **신청완료 후 작성 내용은 수정/확인 불가**하며, 영업일 기준 1~2일 내 담당자가 연락한다.

## 운영팀 기본(베이직) 업무 범위

- 기업 회원 대상 가이드 전달 (기업관리자 등록~개최 신청 절차, 최종결과물 검토 절차)
- 미니인턴 개최 (상세페이지 제작, 개최신청 승인)
- 신청자 명단 전달, OT 종료 후 참여자 합불 처리
- 기획안 작성법 스킬업 강의 승인 (필요 시)
- 중간피드백(서면) 멘토 컨택 및 작성
- 평가 결과를 내부 관리자(빅브라더)에 입력 — 참여자 문자 기본 양식·수료평가 기준 전달 포함
- 종료 후 기업회원 평가상태 검토
- 참여자 문의 답변 (미니인턴/내부 관리자 관련 문의는 운영팀 담당)

OT 진행과 최종 수료평가는 케어(선택) 범위, 기업 섭외·과제 협의는 파트너십(선택) 범위, 참여자 홍보는 프로모션(선택) 범위다. 홍보 성과는 보장하지 않는다.

## 모집 단계

- 모집 기간, 신청 마감일, 참여 대상, 과제 또는 프로그램 설명이 서로 맞는지 확인한다.
- 고객에게 노출되는 문구는 운영 기준과 현재 모집 상태를 기준으로 안내한다.
- 모집 기간 변경 요청이 있으면 변경 가능 여부와 노출 중인 일정 영향을 함께 확인한다.

## 선발 단계

- 선발 관련 문의에는 현재 운영 기준에 따라 신청 상태, 합격 안내, 이후 일정 중심으로 답한다.
- 선발 기준이 별도로 문서화되어 있지 않으면 임의로 기준을 설명하지 않는다.

## 과제 및 진행 단계

- 참여자에게는 과제 제출 방식, 일정, 결과 안내 시점을 명확히 안내한다.
- 과제 제출 관련 예외 상황은 운영 기준에 문서화된 경우에만 단정한다.

## 수료 및 결과 단계

- 수료의 전제 조건은 **최종기획안과 이력서 제출**이다. 제출 확인 후 최종기획안을 평가해 수료 여부를 정한다.
- 미제출은 평가 없이 미수료가 된다. 미수료 안내 시 미제출인지 평가 미달인지 구분해서 파악한다.
- 수료자에게는 수료증이 발급된다. 미수료자용 확인서는 현재 없다.
- 세부 평가 배점·커트라인은 정리된 기준이 없으므로 단정하지 않는다.
- 수료자 수, 수료율, 특정 기간의 결과 현황은 실제 데이터 조회가 필요하므로 `search-data` 영역이다.

## 예외 처리 원칙

- 기준이 문서화된 예외는 해당 기준을 따른다.
- 기준이 없는 예외는 "현재 정리된 운영 기준에는 없어요. 담당자 확인이 필요해요."라고 안내한다.
