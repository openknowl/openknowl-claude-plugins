# 미니인턴 운영 플레이북

이 파일은 확정된 운영 절차만 담는다. 세부 기준이 문서화되어 있지 않으면 단정하지 않는다.

## 기본 운영 흐름

1. 모집 정보 확인
2. 모집 페이지 또는 프로그램 정보 점검
3. 신청자 접수 상태 확인
4. 선발 또는 합격 상태 관리
5. 과제 및 일정 안내
6. 제출 또는 참여 상태 확인
7. 결과 및 수료 상태 안내
8. 후속 문의 대응

## 개최~수료 전체 프로세스 (운영 가이드 기준)

단계별 주체와 대략적 소요기간. 일정 협의 시 이 기준으로 역산한다.

| 단계 | 소요 | 비고 |
|---|---|---|
| 기업 섭외 | 2~3주 | |
| 과제 협의 | 3~5일 | 기업 소통 지연이 잦음 |
| (선택) 강연자 섭외 | 1주 | 기업·과제 확정 후 가능 |
| 미니인턴 개최 | 2일 | 커버이미지 제작, 랜딩 페이지 생성 |
| 홍보물 제작 | 2일 | 포스터, 인스타그램 게시물 |
| 참여자 모집·홍보 | 2주 | |
| 오리엔테이션(OT) | 1일 | 운영: 과제·일정 안내 / 기업: 소개·질의응답 |
| 기획안 작성법 강의 | - | 온라인, 최종기획안 제출일까지 수강 가능 |
| 도움자료 제공 1~3차 | 각 1일 | 3차는 최종 제출 전 체크리스트 |
| 중간피드백 | 1일 | 현직자 멘토 1:1 서면 피드백 |
| 수료평가 | 3~5일 | 최종기획안·이력서 제출 확인 → 최종기획안 평가 |
| 최종결과 발표 | 1일 | 수료증 발급 |

- 사업부 간 개최 요청은 **희망 OT 일자로부터 최소 8주 전**에 협업 요청 보드로 접수한다.

## 개최 요청 시 필요한 것 (기업/요청 부서에서 받아야 함)

- 미니인턴 커버이미지: **592 x 444px, 최대 30MB, JPG/PNG** (흰색 배경에 기업 로고 양식)
- 미니인턴 개최신청서 최종본 (과제 협의 완료 필수)
- 기업/과제 관련 이미지 5장 내외 (상세페이지 삽입용)
- 진행 일정: 모집마감일 / 선발일 / 중간제안서 제출일 / 최종제안서 제출일 / 결과 발표일 / OT일
- OT 장소 (오프라인 시 상세 주소)
- 운영팀 검토 후 개최까지 **1~2일** 소요

## 기업의 개최 신청 절차 (안내용 확정 절차)

1. 미니인턴 회원가입
2. 기업관리자 등록 — 최초로 기업을 등록한 계정은 담당자 내부 심사 후 **마스터 권한** 부여. 이후 가입하는 해당 기업 구성원은 마스터가 승인.
3. 기업정보 작성 — 기본 정보 → 상세 정보 → 이미지 정보 순. **기업정보 등록·수정은 마스터 권한자만 가능.**
4. 미니인턴 개최 신청 — 프로필 > '미니인턴 개최 신청' > 유형(교육형/채용형) 선택 > '추천 미니인턴 불러오기'로 과제 작성 > 신청완료.
5. **신청완료 후 작성 내용은 수정/확인 불가**하며, 영업일 기준 1~2일 내 담당자가 연락한다.

## 운영팀 기본(베이직) 업무 범위

- 기업 회원 대상 가이드 전달 (기업관리자 등록~개최 신청 절차, 최종결과물 검토 절차)
- 미니인턴 개최 (상세페이지 제작, 개최신청 승인)
- 신청자 명단 전달, OT 종료 후 참여자 합불 처리
- 기획안 작성법 스킬업 강의 승인 (필요 시)
- 중간피드백(서면) 멘토 컨택 및 작성
- 평가 결과를 내부 관리자(빅브라더)에 입력 — 참여자 문자 기본 양식·수료평가 기준 전달 포함
- 종료 후 기업회원 평가상태 검토
- 참여자 문의 답변 (미니인턴/내부 관리자 관련 문의는 운영팀 담당)

OT 진행과 최종 수료평가는 케어(선택) 범위, 기업 섭외·과제 협의는 파트너십(선택) 범위, 참여자 홍보는 프로모션(선택) 범위다. 홍보 성과는 보장하지 않는다.

## 모집 단계

- 모집 기간, 신청 마감일, 참여 대상, 과제 또는 프로그램 설명이 서로 맞는지 확인한다.
- 고객에게 노출되는 문구는 운영 기준과 현재 모집 상태를 기준으로 안내한다.
- 모집 기간 변경 요청이 있으면 변경 가능 여부와 노출 중인 일정 영향을 함께 확인한다.

## 선발 단계

- 선발 관련 문의에는 현재 운영 기준에 따라 신청 상태, 합격 안내, 이후 일정 중심으로 답한다.
- 선발 기준이 별도로 문서화되어 있지 않으면 임의로 기준을 설명하지 않는다.

## 과제 및 진행 단계

- 참여자에게는 과제 제출 방식, 일정, 결과 안내 시점을 명확히 안내한다.
- 과제 제출 관련 예외 상황은 운영 기준에 문서화된 경우에만 단정한다.

## 수료 및 결과 단계

- 수료의 전제 조건은 **최종기획안과 이력서 제출**이다. 제출 확인 후 최종기획안을 평가해 수료 여부를 정한다.
- 미제출은 평가 없이 미수료가 된다. 미수료 안내 시 미제출인지 평가 미달인지 구분해서 파악한다.
- 수료자에게는 수료증이 발급된다. 미수료자용 확인서는 현재 없다.
- 세부 평가 배점·커트라인은 정리된 기준이 없으므로 단정하지 않는다.
- 수료자 수, 수료율, 특정 기간의 결과 현황은 실제 데이터 조회가 필요하므로 `search-data` 영역이다.

## 종료 후 후속 연계 (취업지원서비스, 2025-09 기준)

미니인턴 종료 후 구직자파트가 추천인재풀 등록을 이어서 진행한다.

1. 종료 후 선별 — 교육형: 최종기획안 + 운영 PM의 OT 참여 태도 / 채용형: 최종기획안 + 제출 이력서·자소서 + OT 참여 태도를 종합.
2. 선별된 참여자에게 취업지원서비스 등록 희망 여부 확인 문자 → 1차 유선 안내.
3. 미니인턴 양식의 공통이력서 작성 요청 → 검토 후 추천인재풀 등록.
4. '맞춤형 채용 제안 받기' 신청자도 같은 프로세스로 합류한다.

취업지원서비스 내용: 희망 직무 맞춤 채용공고 문자 발송, M클래스 프로그램 추천, 기업 인재추천(선별 후 기업에 이력서 전달·면접 연계). 선별 시에는 희망직무와 현재 취업상태를 중심으로 확인한다.

이력서 첨삭 서비스 (2023-10 가이드 기준 — 최신 여부 확인 필요):

- 현직 멘토가 구글 PDF 댓글 기능으로 첨삭한다. 필수 첨삭 내용은 오탈자·문맥 수정과 총평.
- 회신 기준은 영업일 3일. 첨삭 완료본 전달 시 멘토 정보가 일부 공개된다(이름 일부, 직무, 재직기업, 연차).
- 첨삭 대상은 미니인턴 채용관 공고와 타 플랫폼 공고 모두 가능. 채용관 공고는 '첨삭 후 지원 포기 시 이후 첨삭 이용 불가'를 사전 안내한다(미지원 방지).
- 지원자 서류 업로드 시 이메일·전화번호 등 개인정보는 삭제 후 처리한다.

## 기업 개최 문의·영업 참고 (2025-09 운영팀 정리 기준)

- 기업이 먼저 문의하는 **인바운드 경로**는 세 가지로 분류한다: 검색(인턴 채용·일경험 관련 키워드), 지인 추천, 기존 이용 기업의 재문의.
- 기업이 개최를 **승인하는 주된 이유**: 타겟 사용자의 결과물·서류를 받아볼 수 있음, 결과물로 인재 역량 검증 가능.
- 기업이 개최를 **거절하는 주된 이유**: 내부 리소스 부족, 채용 마감/계획 변경, 비용 부담, 프로젝트(과제) 기획 부담.
- 개최비·채용수수료 금액은 이 스킬에서 단정하지 않는다. 최신 기준은 담당자 확인.
- 채용형은 개최부터 채용까지 통상 1개월 이상 걸린다는 점을 기업에 미리 안내하면 이탈 예방에 도움이 된다.
- **팔로업 중단 기준**: 유선·메일로 최소 3회 이상 연락해도 무응답이면 이용 니즈가 없다고 판단하고 팔로업을 중단한다.
- **리드타임 참고** (2025-12 운영팀 집계): 문의 인입 → 개최 완료 평균 약 3주. 기업이 과제 신청을 마친 뒤부터는 개최까지 평균 약 9일.
- **기업 안내용 표준 일정 개요**: 프로젝트 신청·과제 협의 약 1주 → 개최·참가자 모집 최소 2~3주 → OT·프로젝트 진행 2주 → 최종 기획안 검토. 전체 4주 이상 걸린다는 점을 처음부터 안내한다.

## 기업 만족도조사 운영 (현행)

- 미니인턴 종료 후 기업 담당자에게 메일로 외부 설문(모아폼) 링크를 발송한다. 미응답 시 유선 팔로업.
- 실제 응답 소요는 5~6분 내외 — 사전 안내 문구("2분 내외")와 차이가 있으니 안내 시 주의.
- 만족도가 높은 기업은 SNACK 후기 인터뷰로 연계할 수 있다.

## 피드백 운영 (현행, 2025-12 운영팀 공유 기준)

### 중간피드백 — 서면 (기본)

- **중간기획안 제출자에 한해** 제공한다.
- 두 축으로 구성: 현직자 멘토(기획안의 논리 흐름·실무 관점) + 기업 담당자 한 줄 코멘트(방향성·과제 적합성, OT 종료 후 가능 여부 확인).
- 절차: 멘토 사전 섭외 → 중간기획안 제출 다음날 취합·건수 파악 → 멘토 분배·피드백 요청 → 요청 3일 후 검수(필요 시 보완 요청) → 빅브라더 해당 미니인턴의 피드백란에 업로드 → 완료 공유.

### 중간피드백 — 온라인 1:1 (필요 시)

- 현직자 멘토가 참여자별 20~25분 화상(zoom) 피드백. 서면 피드백은 별도 제공하지 않는다.
- 타임테이블을 셋팅해 멘토·참여자에게 공유하고, 운영진이 진행 상황을 지속 팔로업한다 (멘토 1명당 운영진 최소 1명).

### 최종피드백 (필요 시)

- 현직자 멘토는 중간피드백과 동일 절차. 중간·최종을 한 번에 진행할 수 있는 멘토 위주로 섭외한다.
- 최종 결과 발표일에 빅브라더 또는 메일로 전달한다. 운영팀이 수료평가 내용 기반 총평을 제공한 사례도 있다.
- **경험칙: 최종피드백을 제공하면 미수료 사유 문의가 줄어든다.** 수료/미수료 불만은 결과 자체보다 '설명 부족'에서 나온다 — 미수료 안내 시 사유 설명을 충실히 할 것.
- 최종피드백 유료 상품화는 논의 중 단계다 (2025-12 기준, 미확정). 유료라고 단정하지 않는다.

## 알림톡 안내 (빅브라더에서 수동 발송)

참여자 안내 알림톡은 다음 시나리오 계열로 운영한다 (2025년 설계 기준, 발송은 수동 버튼 방식):

- 합격/불합격 안내
- OT 안내 (전날 1·2차, 당일 리마인드, 종료 후 안내)
- 중간 기획안 제출 독려, 중간피드백 업로드 안내 (제출자/미제출자 구분)
- 최종 기획안 제출 독려
- 수료 결과 안내

발송 전 확인: 합불 상태나 일정이 바뀔 수 있으므로, 상태 확정 후 발송한다. 발송 후 일정이 변경되면 변경 안내를 다시 보낸다.

## 일정 변경 실무 (운영팀 관행 기준)

- 개최 일정 수정은 드물지 않다. 주된 사유: 참여자 이력서 미제출로 제출 마감 연장, 모집 인원 부족으로 OT 날짜 변경.
- OT 날짜 변경은 통상 1주일 전쯤 결정된다.
- 일정을 바꾸면 이미 나간 안내(알림톡·노출 일정)와 어긋나지 않는지 반드시 확인한다.

## 예외 처리 원칙

- 기준이 문서화된 예외는 해당 기준을 따른다.
- 기준이 없는 예외는 "현재 정리된 운영 기준에는 없어요. 담당자 확인이 필요해요."라고 안내한다.
