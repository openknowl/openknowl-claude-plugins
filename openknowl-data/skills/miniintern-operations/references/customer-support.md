# 고객 응대 기준

기업 고객과 참여자에게 답변할 때 쓰는 운영팀 기준이다.

## 공통 원칙

- 확인된 기준만 말한다.
- 내부 시스템명, DB 컬럼명, 원본 문서명은 말하지 않는다.
- 책임 소재가 생길 수 있는 내용은 단정하지 않는다.
- 일정, 수료, 선발, 환불, 비용, 계약 관련 내용은 문서화된 기준이 없으면 담당자 확인이 필요하다고 안내한다.

## 기업 고객 응대

기업 고객에게는 다음 순서로 답한다.

1. 요청 내용을 한 문장으로 확인한다.
2. 현재 운영 기준에서 가능한 처리인지 말한다.
3. 필요한 정보나 다음 액션을 안내한다.
4. 일정이나 결과에 영향이 있으면 함께 말한다.

### 기업 고객 답변 예시

모집 기간 변경 요청을 받은 경우:

```text
요청하신 모집 기간 변경 건 확인했습니다. 현재 노출 중인 일정과 신청자 안내에 영향이 있을 수 있어서, 변경하려는 마감일과 변경 사유를 먼저 확인한 뒤 반영 가능 여부를 안내드리겠습니다.
```

## 참여자 응대

참여자에게는 다음 순서로 답한다.

1. 문의한 상황을 짧게 확인한다.
2. 참여자가 해야 할 다음 행동을 먼저 안내한다.
3. 일정이나 결과 확인 위치를 알려준다.
4. 운영 기준에 없는 예외는 담당 확인이 필요하다고 말한다.

### 참여자 답변 예시

수료 기준 문의를 받은 경우:

```text
수료 여부는 프로그램별 운영 기준과 제출/참여 상태를 기준으로 확인됩니다. 현재 문의하신 건은 세부 프로그램 기준 확인이 필요해서, 담당자가 기준을 확인한 뒤 안내드리겠습니다.
```
